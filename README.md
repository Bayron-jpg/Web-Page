# Web-Page
Página web de prueba con datos reemplazables.

## Requisitos previos
Asegúrate de tener instalado Node.js y npm en tu sistema antes de comenzar. Puedes instalarlos utilizando **NVM** (Node Version Manager):

1. **Descargar e instalar NVM:**

   ```bash
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.3/install.sh
   ```

2. **Recargar la configuración de la terminal:**

   ```bash
   source ~/.bashrc
   ```

3. **Instalar la versión LTS de Node.js:**

   ```bash
   nvm install --lts
   ```

4. **Verificar la instalación:**
   ```bash
   node --version
   npm --version
   ```

## Instalación y Configuración del Proyecto

Pasos para inicializar y ejecutar el proyecto localmente:

1. **Crear el proyecto:**

   ```bash
   npm create vite@latest nombre-del-proyecto -- --template react
   ```

2. **Acceder al directorio del proyecto:**

   ```bash
   cd nombre-del-proyecto
   ```

3. **Instalar dependencias:**

   ```bash
   npm install
   ```

4. **Ejecutar el entorno de desarrollo:**
   ```bash
   npm run dev
   ```
