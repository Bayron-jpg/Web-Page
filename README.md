# Web-Page
Página web de prueba con datos reemplazables.

## Pasos para crear el proyecto
1. Descarga e instala nvm
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.3/install.sh
```

2. Recarga la configuración de la terminal
```bash
source ~/.bashrc
```

3. Instala la versión más reciente con soporte a largo plazo
```bash
nvm install --lts
```

4. Verifica
```bash
node --version
npm --version
```
